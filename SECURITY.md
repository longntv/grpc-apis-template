# Security policy

This repository contains API definitions and generated client/server stubs.

Please report vulnerabilities privately via GitHub
[Security Advisories](../../security/advisories/new) instead of opening a public issue.
You should receive a response within 7 days.

Toolchain or dependency issues (buf, protoc plugins, grpc, protobuf runtimes) are
usually best reported upstream; we will bump the pinned versions once a fix is released.
